Getting it onto the printer

Bambu (X1, P1, A1, A1 mini): in Bambu Studio, slice, then File › Export › Export plate sliced file. Load that here. To print the export, open it in Bambu Studio and use Print plate, or copy it to the SD card.

Prusa, Orca, others: load the plain .gcode. PrusaSlicer writes binary .bgcode for MK4 and XL by default, so turn that off under Printer Settings first.

The print-time estimate inside the file still describes the original print.

Drop a sliced .gcode.3mf or .gcode here

Only outer walls are shown and changed. Orange is fuzzed, blue is left smooth.
