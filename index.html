FuzzySpiral

Drop a sliced .gcode.3mf or .gcode

How it works

FuzzySpiral adds slicer-style fuzzy skin to an already-sliced file, but only where your pattern says. It changes outer walls and nothing else. In the preview, orange is fuzzed and blue is left smooth.

  1. Slice in your slicer with fuzzy skin off.
  2. Open the sliced file here, then pick a preset or stack pattern layers.
  3. Export, and print the exported file.

Bambu (X1, P1, A1, A1 mini)

In Bambu Studio use File › Export › Export plate sliced file (⌘G) and open that .gcode.3mf here. To print the export, open it in Bambu Studio and choose Print plate, or copy it to the SD card.

Prusa, Orca, Klipper and others

Export plain .gcode from the slicer and load it here. PrusaSlicer writes binary .bgcode for the MK4 and XL by default, so turn that off in Printer Settings first.

Patterns

Layers stack top to bottom. The first sets the area, and each one after it combines with the result: union adds its area, intersect keeps only the overlap, subtract cuts it out. Spirals, stripes and checkers wrap around each object's middle, or around a point you pick on the bed (Fuzzy skin › More).

Hover any control for what it does. Save and load patterns with the ⤓ ⤒ buttons next to Pattern.

Good to know

  • The print-time estimate in the file still describes the original print.
  • Arcs in fuzzed walls become straight segments; untouched walls are copied exactly.
